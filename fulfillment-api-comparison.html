  • Paling banyak dipakai di Indonesia

  • Komunitas besar

  • Tracking terbatas (Pro plan)
  • Perlu integrasi terpisah per kurir untuk label
🥉 #3
KirimAja
By SiCepat. Enterprise-grade.
  • By SiCepat (kurir terbesar)
  • API stabil & cepat
  • Multi-courier
  • Insurance & COD support
  • Perlu kontrak bisnis
  • Tidak ada free tier
  • Dokumentasi kurang lengkap

💻 Contoh Integrasi (Biteship)

convex/fulfillment/biteship.ts Contoh implementasi
// Biteship API integration untuk Fulfillment Module // Docs: https://docs.biteship.com const BITESHIP_API_KEY = process.env.BITESHIP_API_KEY; const BITESHIP_BASE_URL = 'https://api.biteship.com/v1'; // 1. Cek ongkir dari semua kurir export async function getShippingRates({ origin, destination, weight, items }) { const res = await fetch(`${BITESHIP_BASE_URL}/rates/couriers`, { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${BITESHIP_API_KEY}`, }, body: JSON.stringify({ origin_area_id: origin, destination_area_id: destination, couriers: 'jne,jnt,sicepat,anteraja,grab,gosend', items: items.map(i => ({ name: i.name, value: i.price, weight: i.weight, quantity: i.qty, })), }), }); return res.json(); } // 2. Create shipment & generate label export async function createShipment({ courier, origin, destination, items, sender, recipient }) { const res = await fetch(`${BITESHIP_BASE_URL}/orders`, { method: 'POST', headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${BITESHIP_API_KEY}`, }, body: JSON.stringify({ shipper: sender, origin: origin, destination: recipient, courier: courier, delivery: { type: 'now' }, items: items, }), }); return res.json(); } // 3. Webhook handler untuk tracking updates export async function handleTrackingWebhook(payload) { // Biteship webhook: status_changed const { order_id, status, courier, history } = payload; // Map Biteship status → internal status const statusMap = { 'picking_up': 'picking', 'picked': 'packed', 'dropping_off': 'shipped', 'in_transit': 'in_transit', 'delivered': 'delivered', 'cancelled': 'cancelled', 'returned': 'returned', 'failed': 'exception', }; return { trackingId: order_id, status: statusMap[status] || status, courier: courier, history: history, }; }

📋 Rekomendasi Implementasi

Fase Implementasi
1

Fase 1: Manual Tracking (Tanpa API)

Input tracking number manual, update status manual. Tidak perlu API key. Langsung usable.

⏱️ Effort: 1-2 hari · 💰 Cost: Rp 0
2

Fase 2: Rajaongkir (Cek Ongkir)

Integrasi Rajaongkir Starter (gratis) untuk cek ongkir multi-kurir. Customer bisa pilih kurir saat checkout.

⏱️ Effort: 1 hari · 💰 Cost: Rp 0 (Starter)
3

Fase 3: Biteship (Full Integration)

Create shipment otomatis, generate label, webhook tracking real-time, notifikasi customer.

⏱️ Effort: 3-5 hari · 💰 Cost: Rp 0-500rb/bln (tergantung volume)
4

Fase 4: KirimAja (Enterprise)

Kalau volume tinggi (>1000 paket/bln), negosiasi rate khusus via KirimAja/SiCepat.

⏱️ Effort: 1-2 minggu · 💰 Cost: Custom
