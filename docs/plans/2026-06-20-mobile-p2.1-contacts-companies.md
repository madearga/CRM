## Backend contracts (verified, do not change)

```
api.contacts.list({ search?, companyId?, paginationOpts })  // usePaginatedQuery
  → { page: ContactListItem[], continueCursor, isDone }
    ContactListItem: { id, companyId?, fullName, email?, phone?, jobTitle?,
                       lastTouchedDays, lastTouchStatus:'green'|'red',
                       lifecycleStage?, tags? }

api.contacts.getById({ id })  // useQuery  (throws ConvexError NOT_FOUND)
  → { id, companyId?, companyName?, dealCount, email?, phone?, jobTitle?,
      fullName, lifecycleStage?, notes?, tags?, lastTouchedDays, lastTouchStatus }

api.companies.list({ search?, includeArchived?, paginationOpts })  // usePaginatedQuery
  → { page: CompanyListItem[], continueCursor, isDone }
    CompanyListItem: { id, name, website?, industry?, size?, status?, country?, tags? }

api.companies.getById({ id })  // useQuery  (returns null when not found)
  → { id, name, website?, industry?, size?, address?, country?, notes?, status?,
      contactsCount, dealsCount, pricelistName?, ... } | null
```

Note the asymmetry: `contacts.getById` **throws** `NOT_FOUND`; `companies.getById` returns **null**. Handle both.

## Navigation model

- Entry via **More menu** rows ("Contacts", "Companies") → push nested stacks. Keeps the 4-tab shell clean.
- New route groups: `app/(app)/contacts/` (`_layout.tsx` stack, `index.tsx`, `[id].tsx`) and `app/(app)/companies/` (`_layout.tsx` stack, `index.tsx`, `[id].tsx`).
- Cross-link: contact detail → tap company → company detail → "contacts at company" (calls `api.contacts.list({ companyId })`).

## Infra (Task A) — built once, reused by every Phase-2 list

- Re-export `usePaginatedQuery` from `convex/react` in `apps/mobile/src/hooks/use-convex.ts` (currently exports only `useQuery/useMutation/useAction/useConvex`).
- `apps/mobile/src/hooks/use-debounced-search.ts` — `useState` input + debounced value (default 250ms). Tiny, reused by every list screen.
- `apps/mobile/src/components/search-list.tsx` — composes: search `<TextInput>`, a `FlatList`, loading skeleton (reuse `Skeleton`), empty state (reuse `EmptyState`), and a "load more" footer. Props: `items`, `onEndReached`, `searchValue`, `onSearchChange`, `status`, `renderItem`, `emptyCta`, `keyExtractor`. No premature abstraction beyond this (ponytail: wrap a FlatList, not a wrapper-of-a-wrapper).
